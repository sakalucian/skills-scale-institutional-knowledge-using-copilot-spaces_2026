# Process Document Update Checklist

Use this checklist when proposing or merging updates to program process documents in docs/.

- [ ] Completed ISSUE_TEMPLATE form (`.github/ISSUE_TEMPLATE/add-update-content-to-process-docs.yml`) and linked issue created
- [ ] Content aligns with existing process docs and naming conventions
- [ ] Update improves clarity or closes a documented gap
- [ ] Acceptance criteria are specified and measurable
- [ ] Stakeholders or owners have been notified or reviewers assigned
- [ ] New files added under docs/ and follow repo styling guidelines
- [ ] Cross-links to related process docs included
- [ ] Add changelog note in the doc header (date and summary)
- [ ] Tests or examples updated where applicable
